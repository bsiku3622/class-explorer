# ExamsPage

`/exams`에서 선택 학기의 본인 시험 시간표를 표시합니다. API는
`lib/examsApi.ts`, 날짜별 묶음과 KST 표시는 `lib/examSchedule.ts`가 담당합니다.

날짜별로 실제 시작·종료 시각, 시험 과목, 분반, 시험실을 표시합니다. 시험이 없는 날도
남겨 시험 주간 전체를 보여 줍니다. 시험실 미확정은 공지의 분반 배정 원문을 표시하고,
별도 실시 과목은 날짜 칸에 넣지 않고 별도 안내에 표시합니다. 좁은 화면에서는 한 열,
넓은 화면에서는 2~5열로 배치합니다. 학기 전환 때 이전 응답이 새 학기 화면에
남지 않도록 회차 학기를 확인하고, 지난 요청은 AbortController로 취소합니다.
