# pages/LandingPage.tsx Guide

> [← Frontend Guide](../../CLAUDE.md)

## 역할
로그인하지 않은 사람이 주소 `/` 로 왔을 때 보는 **공개 소개 화면**입니다. 앱 안쪽은
전부 계정을 요구하므로, 밖에서 읽히는 설명은 이 화면 하나뿐입니다.

라우팅은 `App.tsx` 가 정합니다 — `sessionToken` 이 없고 주소가 `/` 일 때만 이 화면이고,
다른 주소면 `LoginPage` 입니다. 자세한 것은 [App.guide.md](../App.guide.md).

## ⚠️ 실제 데이터를 넣지 마세요

로그인 **앞**에 있는 화면이라 누구나 봅니다. 화면 예시(`MockNow`·`MockSearch`·
`MockEmptyRooms`)에 쓰는 이름·과목·교실은 **전부 지어낸 것**이고 앞으로도 그래야 합니다.
진짜 명단을 한 줄이라도 넣으면 그 순간 전교생 정보가 공개됩니다.

같은 이유로 통계 숫자도 넣지 않았습니다. "과목 109개" 같은 값은 학기마다 달라져 금방
낡고, 정확히 맞추려면 로그인 없이 읽히는 API 가 하나 필요해집니다.

## Props
| prop | 타입 | 설명 |
|------|------|------|
| `onStart` | `() => void` | 로그인 화면으로 넘기는 콜백 (`/login` 이동) |

## 구성
```
머리띠        로고 + 로그인 버튼
히어로        기울인 대제목 + 설명 + 버튼 둘 + 가짜 화면 콜라주
세 가지       검은 띠 · 01/02/03
기능          카드 여덟 + 위젯 한 줄
데이터        로그인 없이는 아무것도 안 보인다는 설명 셋
자주 묻는 것   카드 넷
마지막 CTA    보라 띠 + 로그인
푸터          저장소 링크
```

가짜 화면 콜라주는 **`lg` 이상에서만** 기울여 겹칩니다. 좁은 화면에서는 `MockNow` 한
장만 세로로 놓습니다 — 겹쳐 놓으면 서로를 가리고, 회전한 상자가 화면 밖으로 나갑니다.

## 자주 밟는 것

`RetroButton` 의 `variant="white"` 는 **면만 칠하고 글자색은 물려받습니다.** 마지막 CTA
구역은 `text-white` 라서 흰 버튼에 흰 글자가 나왔습니다. 어두운 바탕 위에 흰 버튼을 둘
때는 `className="text-black"` 을 같이 주세요.

## 곁딸린 파일
`index.html` 의 `description`·`og:*` 와 `public/robots.txt`·`public/sitemap.xml` 이 이
화면을 위해 있습니다. 크롤러가 읽는 것은 `/` 하나뿐이고, 나머지 주소는 로그인 화면만
나와서 색인에 남으면 "빈 페이지" 로 읽힙니다 — 그래서 `robots.txt` 에서 막습니다.
