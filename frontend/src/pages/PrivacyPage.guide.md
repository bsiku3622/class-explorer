# pages/PrivacyPage.tsx Guide

> [← Frontend Guide](../../CLAUDE.md)

## 역할
개인정보처리방침. **로그인 없이 열리는 두 번째 화면**입니다(`/privacy`). 로그인해야
읽히는 방침은 방침 구실을 못 합니다.

## 담는 항목은 법이 정합니다

「개인정보 보호법」제30조 제1항 각 호와 같은 법 시행령 제31조가 필수 기재사항을
정합니다. 순서를 바꾸는 건 상관없지만 **항목을 빼면 안 됩니다.**

| 화면의 절 | 근거 |
|---|---|
| 1. 처리하는 개인정보 항목 | 시행령 제31조 제1호 |
| 2. 처리 목적 | 법 제30조 제1항 제1호 |
| 3. 정보주체 이외로부터 수집한 출처 | 법 제20조 |
| 4. 처리 및 보유 기간 | 법 제30조 제1항 제2호 |
| 5. 제3자 제공 | 법 제30조 제1항 제3호 |
| 6. 위탁·국외 이전 | 법 제30조 제1항 제4호, 시행령 제31조 제2호, 법 제28조의8 |
| 7. 자동 수집 장치 | 법 제30조 제1항 제7호 |
| 8. 정보주체의 권리 | 법 제30조 제1항 제5호 |
| 9. 개인정보 보호책임자 | 법 제30조 제1항 제6호, 제31조 제2항 |
| 10. 안전성 확보 조치 | 시행령 제31조 제3호 |
| 11. 파기 | 법 제30조 제1항 제3호의2 |

**6절의 국외 이전 표는 제28조의8 제2항의 칸을 다 갖춥니다** — 받는 자와 연락처, 국가, 항목, 이전 시기,
목적, 보유 기간. 표 위에 이전 근거(제28조의8 제1항 제3호, 계약 이행에 필요한 처리위탁·보관)를, 아래에
거부 방법과 그 결과를 적었습니다. 사업자를 더하면 칸을 비우지 마세요.

**광고는 없습니다.** 한때 애드센스 심사용 광고 쿠키 문단(Google·제3자 쿠키, `google.com/settings/ads`·
`aboutads.info` 거부 안내)이 7절에 있었는데, 실제 사이트에 광고 스크립트가 붙은 적이 없어 2026-10 감사 때
뺐습니다. 광고를 붙이면 그 문단을 7절에 되살리고 6절 Google 행에 광고를 더해야 합니다 — 셋 중 하나라도
빠지면 애드센스 정책 위반입니다.

## ⚠️ 코드를 고치면 이 화면도 고칩니다

여기 적힌 것과 실제가 어긋나면 방침이 아니라 거짓말이 됩니다. 2026-10 감사에서 실제로 어긋난 자리가
여럿 나왔습니다(Cloudflare 경유, 서버 로그, 글꼴, 브라우저 저장, 계정 삭제, 백업 보관) — `logs.md`.
특히 아래를 건드렸으면 같이 보세요.

- 수집 항목 — `models.py` 의 `User`·`Session`·`Material`·`EventRequest` 컬럼과 자료 파일
- 전공 — `User.major`·`major_answered_at` 과 그걸 쓰는 자리(1·2·4·8절). 고르는 창이 수강 이력으로
  짐작한 트랙을 **저장하지 않는다**고 적었으니, 짐작을 남기기 시작하면 2절도 고칩니다. 관리자가
  **인원 수만** 본다고도 적었습니다(`GET /majors/stats`)
- **Ask 가 모델에 보내는 것** — `backend/agent/chat.py` 의 시스템 프롬프트(이름·학번·학년·구분·전공과 이번
  학기 수업)와 도구 결과(다른 학생의 시간표·명단, 본인 일정·시험, 게시글 원문, 강의계획서 본문). 2절, 6절
  OpenAI 행, 10절에 적혀 있습니다 — 프롬프트에 넣는 걸 늘리면 셋 다. 한동안 이름·학번을 뺐다가 되돌렸습니다
  (모델이 "내 학번 뭐야?" 에 남의 이름을 지어냈습니다). 강의계획서는 교사 전화번호·이메일을 지우고 보낸다고
  10절에 적었습니다(`services/syllabi.py` 의 `text`)
- **AI 모델 제공자** — `backend/agent/llm.py` 의 `resolve()` 가 OpenAI 를 **이용자가 고른 경우에만** 고르고
  게시글 분석은 로컬로만 합니다. 6절이 그렇게 약속하니 이 규칙을 풀면 6절도
- **국외 사업자** — Cloudflare(모든 요청·응답이 지나감), Netlify(화면 파일), Google(학번 확인·Google Fonts),
  jsDelivr(Pretendard), OpenAI. 글꼴을 직접 호스팅하면 Google·jsDelivr 의 글꼴 부분을 빼고, 호스팅이나
  DNS 를 옮기면 그 행을 고칩니다. 화면이 새 외부 주소(CDN·분석·폰트)를 부르기 시작하면 여기에 더합니다
- 세션 보관 기간 — `backend/core/auth.py` 의 `SESSION_EXPIRE_DAYS` (지금 30일, 4절). 만료 세션은
  로그인 때 지웁니다(`routers/auth.py`)
- **서버 로그** — 웹 서버(nginx) 14일, 서비스 기록(journald) 90일이라고 4·11절에 적었습니다. 서버 설정
  (`/etc/logrotate.d/nginx`, journald `MaxRetentionSec`, API 유닛의 `--no-access-log`)을 바꾸면 같이 —
  `deploy-guide.md`
- **백업** — 1년 지나면 지우고(`services/backup.py` 의 `KEEP_DAYS`), 세션과 게시글 파생물은 넣지
  않는다고(`scrub_backup`) 4·10·11절에 적었습니다. 본 DB 를 복사하는 새 길을 만들면 그 약속이 깨집니다
  (`backend/core/db.guide.md`)
- **브라우저 저장** — 7절 표가 키마다 내용과 지우는 때를 적습니다. `localStorage`·`sessionStorage` 에
  새 키를 넣거나, 로그아웃 때 지우는 것(`App.tsx` 의 `handleLogout`)을 바꾸면 표도
- **계정 삭제** — 그 계정의 기록을 함께 지운다고 4·8절에 적었습니다(`routers/admin.py` 의 `_forget_user`)
- **강의계획서** — 로그인해야 받는다고 1·2·4·10절에, Ask 가 읽는다고 2·6절에 적었습니다. 다시 공개 번들에
  넣지 마세요. 1·3절은 "학기별(2023~2026학년도)" 입니다 — 2026-1 것만 있는 게 아닙니다
- ksain 수집 범위·보관 — `backend/ksain/` (1·3·4절). 원문이 지워진 글의 사본을 지운다고 적었으니
  `sync.refresh` 의 그 동작을 빼면 4절도 고쳐야 합니다
- AI 질문의 저장 여부 — 지금은 서버에 남기지 않습니다(4절). 질문 기록을 쌓기 시작하면 고치세요

`UPDATED` 상수가 시행일입니다. 내용을 바꾸면 이 값도 올리세요. **방침은 고쳐 싣는 날 바로 시행합니다**
(13절) — 예전엔 7일·30일 전에 알린다고 적었다가, 2026-10 개정 때 운영자 결정으로 뺐습니다.

## 표는 가로로 흘립니다
`min-w-[40rem]` + `overflow-x-auto` 입니다. 좁은 화면에서 줄바꿈으로 뭉개면 어느 칸의
값인지 못 읽어서, 접는 대신 흘립니다. 첫 칸은 `whitespace-nowrap` 으로 고정합니다. 열이 많은
6절 표는 `wide` 로 `min-w-[60rem]` 을 줍니다 — 40rem 에 여섯 칸을 넣으면 칸마다 글자가 세로로 쌓입니다.
