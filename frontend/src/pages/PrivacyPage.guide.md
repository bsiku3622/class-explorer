# pages/PrivacyPage.tsx Guide

> [← Frontend Guide](../../CLAUDE.md)

## 역할
개인정보처리방침. **로그인 없이 열리는 두 번째 화면**입니다(`/privacy`). 로그인해야
읽히는 방침은 방침 구실을 못 하고, 애드센스 심사도 이 주소를 직접 봅니다.

## 담는 항목은 법이 정합니다

「개인정보 보호법」제30조 제1항 각 호와 같은 법 시행령 제31조가 필수 기재사항을
정합니다. 순서를 바꾸는 건 상관없지만 **항목을 빼면 안 됩니다.**

| 화면의 절 | 근거 |
|---|---|
| 1. 처리하는 개인정보 항목 | 시행령 제31조 제1호 |
| 2. 처리 목적 | 법 제30조 제1항 제1호 |
| 3. 정보주체 이외로부터 수집한 출처 | 법 제20조 |
| 4. 처리 및 보유 기간 | 법 제30조 제1항 제2호 |
| 5. 제3자 제공 | 법 제30조 제1항 제3호 |
| 6. 위탁·국외 이전 | 법 제30조 제1항 제4호, 시행령 제31조 제2호 |
| 7. 자동 수집 장치(쿠키) | 법 제30조 제1항 제7호 |
| 8. 정보주체의 권리 | 법 제30조 제1항 제5호 |
| 9. 개인정보 보호책임자 | 법 제30조 제1항 제6호, 제31조 제2항 |
| 10. 안전성 확보 조치 | 시행령 제31조 제3호 |
| 11. 파기 | 법 제30조 제1항 제3호의2 |

7절의 **광고 쿠키 문단**은 애드센스가 게시자에게 요구하는 고지입니다 — Google 과 제3자
공급업체의 쿠키 사용, `google.com/settings/ads` 와 `aboutads.info` 거부 안내가 그것이고,
셋 중 하나라도 빠지면 정책 위반입니다. 반대로 **광고를 내리면 이 문단도 걷어야** 합니다.

## ⚠️ 코드를 고치면 이 화면도 고칩니다

여기 적힌 것과 실제가 어긋나면 방침이 아니라 거짓말이 됩니다. 특히 아래를 건드렸으면
같이 보세요.

- 수집 항목 — `models.py` 의 `User`·`Session` 컬럼
- 세션 보관 기간 — `auth.py` 의 `SESSION_EXPIRE_DAYS` (지금 30일, 화면 4절에 적혀 있음)
- 국외 이전 대상 — 호스팅이나 외부 서비스를 바꿨을 때 6절

`UPDATED` 상수가 시행일입니다. 내용을 바꾸면 이 값도 올리세요.

## Props
| prop | 타입 | 설명 |
|------|------|------|
| `onBack` | `() => void` | 소개 화면으로 돌아가는 콜백 |

## 표는 가로로 흘립니다
`min-w-[40rem]` + `overflow-x-auto` 입니다. 좁은 화면에서 줄바꿈으로 뭉개면 어느 칸의
값인지 못 읽어서, 접는 대신 흘립니다. 첫 칸은 `whitespace-nowrap` 으로 고정합니다.
