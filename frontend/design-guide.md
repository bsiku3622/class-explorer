# Frontend Design Guide

> [← 프로젝트 전체 가이드](../CLAUDE.md) | 토큰 원본: [`src/index.css`](src/index.css) 의 `@theme`

**스타일**: 레트로 브루탈리즘 — 굵은 테두리, 하드 쉐도우, 물리적 버튼 피드백

## 색상 토큰

**값의 원본은 `src/index.css` 의 `@theme` 하나뿐입니다.** 아래 표는 그걸 옮겨 적은
것이라, 토큰을 고치면 여기도 같이 고쳐야 합니다 — 한동안 이 표가 실제 값과 전부
어긋나 있었고, 표를 믿고 색을 고른 화면이 엉뚱한 색으로 나왔습니다.

| 토큰 | 값 | 쓰이는 곳 |
|------|----|------|
| `retro-bg` | `#fff5d1` | 전체 배경 (크림). 사이드바도 같은 색입니다 |
| `retro-fg` | `#222222` | 기본 글자색. **테두리는 이게 아니라 `black`(#000) 입니다** |
| `retro-primary` | `#ff4eba` | 핑크. 홈에서는 **"지금"**, 통계 막대 기본색 |
| `retro-secondary` | `#7828c8` | 보라. 상단 바·하단 바 같은 **어두운 면** |
| `retro-accent-light` | `#f0fdff` | 아주 옅은 시안. 목록·버튼 호버 배경 |
| `retro-accent1` | `#3decfd` | 시안. 홈의 Trade 배너, 강조 칸 |
| `retro-accent2` | `#ffd500` | 노랑. 급식 아침, 여름방학 막대 |
| `retro-accent3` | `#ff4eba` | 핑크 — ⚠️ `retro-primary` 와 **같은 값**입니다 |
| `retro-accent4` | `#ff9100` | 주황. 급식 점심, 분반 상태 |
| `retro-accent5` | `#00c8ff` | 하늘. 겨울방학 막대, 생활관 일정 |
| `retro-green` | `#00c22a` | 초록. 빈 교실, 성공 상태 |

⚠️ **`retro-primary` 와 `retro-accent3` 은 같은 핑크입니다.** 한쪽만 바꾸면 같은 뜻이던
두 자리가 조용히 갈라집니다 — 색을 바꿀 일이 생기면 둘 다 보세요.

⚠️ **테두리에 `retro-fg` 를 쓰지 마세요.** 글자는 `#222222`, 테두리는 순수 검정입니다
(`border-2 border-black`). 브루탈리즘의 굵은 선은 완전한 검정일 때만 제대로 섭니다.

## 학과별 색상 (홈)

**홈의 네 자리가 같은 색을 씁니다** — 히어로 제목·왼쪽 띠, 자(`DayRuler`)의 칸, 오늘
목록의 줄 띠와 과목명, 주간 격자의 칩. 값은 `getDepartmentColor()`
(`src/lib/utils.ts`) 하나에서 나옵니다.

| 학과 | Hex | | 학과 | Hex |
|---|---|---|---|---|
| 수학 | `#7828c8` | | 국어 | `#dc2626` |
| 정보과학 | `#2563eb` | | 사회 | `#b45309` |
| 물리학 | `#4f46e5` | | 외국어 | `#0891b2` |
| 화학 | `#ea580c` | | 예체능 | `#ca8a04` |
| 생물학 | `#16a34a` | | 융합 | `#64748b` |
| 지구과학 | `#0d9488` | | (없음) | `#64748b` |

⚠️ **핑크(`retro-primary`) 계열을 넣지 마세요.** 그건 "지금" 한 뜻으로 예약돼 있고,
학과색은 8~14%로만 깔리므로 100%로 채우는 "지금"과 섞이지 않습니다.

**칠하는 법은 자리마다 같습니다** — `배경 = 학과색 8~14%`, `테두리 = 학과색 100%`,
`글자 = 학과색 100%`. 이 문법을 지키면 새 자리를 만들어도 색이 따로 놀지 않습니다.

## "지금" 은 세 자리에서 같은 얼굴입니다

⚠️ **형광 핑크로 꽉 채우지 마세요.** 자·목록·격자 어디서든 100% 로 칠하면 그 칸
하나가 화면에서 제일 센 물건이 되어 **옆을 읽는 걸 방해합니다.** 학과색 칩과 **같은
문법**을 쓰되 색만 핑크입니다.

```
면:    rgba(255,78,186,0.22)   (목록 줄은 0.12)
테두리: #ff4eba
글자:   #ff4eba
```

⚠️ **자·격자에서는 공강·점심에 "지금" 을 붙이지 않습니다.** 핑크는 "지금 뭘 하고 있다"
는 뜻이라, 아무 일도 없는 자리가 제일 세지면 안 됩니다 — 그 시간대는 자의 검은 캐럿이
짚고 지나갑니다.

**목록(`TodayTimeline`)은 예외입니다.** 여기엔 **캐럿이 없어서**, 공강 시간에 목록만
보면 지금이 어디인지 짚어 주는 게 하나도 없었습니다. 그래서 공강 줄도 진행 중이면
같은 문법으로 칠하되 **수업 줄보다 옅게** 둡니다.

```
수업 · 지금:  border-y-2 #ff4eba + 면 12% + 과목명 핑크
공강 · 지금:  border-y-2 #ff4eba + 면  8% + "공강" 핑크 (시각·교시는 검정)
```

⚠️ 두 농도가 뒤집히면 안 됩니다 — 진행 중인 수업이 화면에서 늘 더 무거워야 합니다.

## 타이포그래피
- **폰트**: Pretendard Variable
- **섹션 소제목**: `text-sm font-bold text-black/40 uppercase tracking-widest flex items-center gap-2`
- **아이콘 (소제목)**: `size={18} className="text-black/40"`
- **대형 제목**: `text-4xl font-black tracking-tighter uppercase`
- **통계 라벨**: `text-sm font-black uppercase`
- **배지**: `text-[10px] font-black`

## 테두리 & 구분선
```
카드/버튼/컨테이너:  border-2 border-black
내부 구분선:        border-black/10  또는  divide-black/10
```

## 쉐도우 & 애니메이션 (핵심)
"그림자가 버튼 안으로 숨는 물리 피드백" 패턴:
```
기본:       shadow-[4px_4px_0_0_rgba(0,0,0,0.2)]
호버:       shadow-[0_0_0_0_rgba(0,0,0,0.2)] translate-x-1 translate-y-1
전환:       transition-all duration-100
카드(큰):   shadow-[6px_6px_0_0_rgba(0,0,0,0.2)]
```

선택된 버튼 (검정 배경):
```
normal:  scale-105 shadow-[4px_4px_0_0_rgba(0,0,0,0.2)]
hover:   shadow-[0_0_0_0_rgba(0,0,0,0.2)]  (translate 없음)
active:  scale-100
```

⚠️ **`color` 를 준 버튼에는 `scale-105` 를 걸지 않습니다.** 확대하면 테두리도 같이
2px → 2.1px 로 커져서 **선이 굵어진 것처럼** 보이는데, 나란히 붙은 버튼 무리(급식
끼니 같은)에서는 그게 크기 차이가 아니라 굵기 차이로 읽힙니다. 색이 이미 "골랐다" 를
충분히 말하므로 확대는 덧붙임일 뿐입니다.

## 카드 패턴
```
기본 카드:     bg-white border-2 border-black shadow-[6px_6px_0_0_rgba(0,0,0,0.2)]
호버 카드:     hover:-translate-y-1.5 transition-transform
RetroCard:    border-2 border-black (bg 없음 — className으로 별도 지정)
```

## 기능별 규칙

### 시간표 그리드 (빈 교실 / 비교)
```
빈 교실:   bg-retro-green/20          (RoomsPage)
점유됨:    bg-black/[0.07] grayscale
선택됨:    bg-black
```

**초록 마름모**(`h-1.5 w-1.5 rotate-45 bg-retro-green`)는 여기가 아니라 **달력의 개인
일정 표식**입니다 (`CalendarGrid`·`CalendarPage`). 같은 모양을 다른 뜻으로 쓰지 마세요.

### 하루 시간 축 (홈의 `DayRuler` + `TodayTimeline`)

⚠️ **카드 안에 카드를 넣지 마세요.** 한때 자를 테두리 있는 칸 열한 개로, 목록을 줄마다
`border-2` 로 그렸는데 — 카드 안에 카드가 열아홉 개 든 꼴이라 전부 같은 무게로 떠들고
정작 "지금" 이 묻혔습니다. **테두리는 바깥 카드 하나**, 안쪽은 `black/10` 구분선입니다.

```
자 · 트랙:      min-w-[60rem] + overflow-x-auto overflow-y-hidden py-1
               ↳ **칸이 4:3 이 되는 폭**입니다 (하루 760분 / 교시 50분 × 64px)
               ↳ ⚠️ `overflow-x-auto` 만 주면 `overflow-y` 가 auto 로 계산돼
                 하드 쉐도우 2px 때문에 **세로 스크롤이 생깁니다** — 명시로 잠그고
                 그림자 자리는 `py-1` 로 비웁니다
자 · 열 때:      **지금을 가운데** (`scrollLeft = 트랙폭 × 비율 − 상자폭/2`)
자 · 높이:      h-10 md:h-12
자 · 칸:        교시마다 border-2 + 11px 번호. **번호가 곧 이름표입니다**
자 · 연강:      **한 칸으로 잇습니다** (과목·분반·교실·시간 인접) · 번호는 `10–11`
자 · 수업 예정:  학과색 테두리 + 14% 채움 + shadow-[2px_2px_0_0_…0.2]
자 · 수업 지금:  #ff4eba 테두리 + 22% 채움 + shadow-[3px_3px_0_0_…0.18]
자 · 수업 지남:  같은 학과색에 **opacity 0.4** · 그림자 없음
자 · 공강:      border-dashed border-black/20 · 배경 없음 · text-black/25
자 · 점심·저녁:  빗금 rgba(0,0,0,0.13) 0 3px / transparent 3px 7px
               ↳ 양옆을 **쉬는시간(10분)만큼 물려** 칸 사이 간격과 리듬을 맞춥니다
지금 캐럿:      w-0.5 bg-black + 위에 마름모(h-2 w-2 rotate-45) · transition-[left] 700ms
눈금 글자:      9px black/30 (덩어리 양 끝) + 구멍 이름 "점심"·"저녁"
목록:          divide-y divide-black/10 · 테두리 없음
목록 · 줄 높이:  **교시 수 × 3.25rem** — 100분짜리 연강은 50분 수업의 두 배입니다
               ↳ 공강도 같은 한 칸. 같은 시간인데 높이가 다르면 목록이 시간을 재는
                 물건이 아니게 됩니다
목록 · 왼쪽 띠:  w-1 학과색 (지금이면 #ff4eba)
줄 · 지금:      border-y-2 border-retro-primary + bg 12% + 과목명 핑크
줄 · 지남:      opacity-55  (40 은 "지났다" 가 아니라 "안 읽힌다" 였습니다)
글자 하한:      **12px** — `김정은 · 1분반` 같은 부연을 10px 로 줄였더니 안 읽혔습니다.
               줄이 답답하면 글자가 아니라 **여백**(줄 높이)을 건드립니다
빈 시간:       11px black/30 · 앞에 4px 짧은 선
방학 막대:      남은 쪽만 계절색 · 지나간 쪽은 빗금
```

⚠️ **자의 칸에는 반드시 교시 번호를 답니다.** 번호 없이 막대만 두면 그게 몇 교시인지
알 방법이 없어 아래 목록과 연결이 끊깁니다. 색을 빼고 무늬(빗금 두 종류)로 성격을
주려다 더 안 읽히게 만든 적이 있습니다 — **부족한 건 장식이 아니라 이름표였습니다.**

**테두리는 칸마다 두릅니다.** 바깥을 하나로 감싸면 교시 사이 쉬는시간(10분)이 칸
안쪽의 여백처럼 보여 칸을 세어야 알 수 있습니다 — 칸마다 두르면 쉬는시간이 칸 사이의
**틈**으로 그냥 보입니다. (위에서 카드 안 카드를 금지한 규칙과 부딪히지 않는 이유는
이게 목록이 아니라 **눈금**이어서입니다 — 칸 하나하나가 데이터입니다.)

⚠️ **면을 채우는 건 "지금" 하나뿐입니다.** 자에서는 남은 수업까지 검게 칠했더니 하루가
통째로 쨍했고 — 내 수업인지 아닌지는 **테두리**(실선 vs 점선)가 이미 가르고 있습니다.

⚠️ **지난 수업도 채우지 않습니다.** 한동안 `bg-black/15` 로 칠해 뒀는데, 저녁에 열면
지나간 칸이 예닐곱이라 **자가 통째로 잿빛 덩어리**가 됐습니다("탁하다" 는 말이 나온
자리가 여기입니다). 위 규칙을 어긴 게 자기 자신이었던 셈입니다 — 지남과 예정은
**테두리 세기와 그림자 유무**로 충분히 갈립니다.

| | 테두리 | 배경 | 그림자 |
|---|---|---|---|
| 예정 | `border-black` | 흰색 | `2px 2px` |
| 지남 | `border-black/25` | 흰색 | 없음 |
| 지금 | `border-black` | **핑크** | `3px 3px` |
목록에서는 진행 중인 줄만 카드 여백까지 꽉 채워 흐르고 나머지는 흰 바탕에 글자만
있습니다 — 그래야 "지금" 이 목록 안의 한 칸이 아니라 지나가는 구간으로 읽힙니다.

**학과색은 옅게 깔 때만 됩니다.** 한때 학과 팔레트를 **면으로 꽉 채워** 봤는데 하루가
색표처럼 보이고 "지금" 이 묻혔습니다 — 그때 내린 결론("색을 쓰지 말자")이 틀렸고,
문제는 **농도**였습니다. 8~14% 로 깔고 100% 는 "지금" 에만 남기면 색이 소음이 아니라
좌표가 됩니다.

⚠️ **지난 수업을 회색으로 덮지 마세요.** `bg-black/15` 로 칠했더니 저녁에 열면 지나간
칸이 예닐곱이라 자가 통째로 **잿빛 덩어리**였습니다("탁하다" 는 말이 나온 자리입니다).
같은 학과색을 **투명도**로 낮추면 오전에 뭘 들었는지가 그대로 남습니다.

빈틈은 두 종류이고 뜻이 다릅니다 — **칸 사이의 흰 틈**은 10분 쉬는시간, **빗금**은
점심·저녁처럼 수업이 놓일 수 없는 구간입니다.

**타입 스케일이 있어야 시선이 멈춥니다.** 전부 10~15px `font-black` 이면 초점이
없습니다 — 시계 24px / 과목 17px / 시각 15px / 부연 11px / 눈금 9px.

### 주간 격자 (홈의 `WeekTimetable`)

자가 **하루**를 재는 물건이라면 이건 **한 주의 모양**을 보는 물건입니다. 같은 언어를
씁니다 — 칸마다 테두리, 빈 자리는 진짜 비움, 채우는 건 "지금" 하나.

```
행 높이:        h-24 md:h-28 xl:h-20   ← 칸이 4:3 이 되는 값. xl 은 오늘 목록과
                                        나란히 서면서 격자 폭이 절반이 됩니다
교시 번호 열:    4rem · 12px black/45 · **세로 가운데** · `1교시` 처럼 단위까지
요일 머리:      bg-black/[0.03] 13px · **오늘만 bg-retro-primary/25 + 핑크 글자**
               ↳ ⚠️ 위아래를 굵은 검정(`border-2`)으로 감싸지 마세요 — 격자에서
                 제일 무거운 덩어리가 **정보가 제일 적은 줄**이 됩니다
오늘 열 기둥:    bg-retro-primary/[0.07] · `gridRow: 2 / span {행 수}`
               ↳ ⚠️ `2 / -1` 은 **안 됩니다.** 행이 암시적 그리드라 `-1` 이 끝을
                 못 짚고 조용히 **헤더 한 칸 높이**로 쪼그라듭니다
바탕 격자선:     border-black/10 — 가로·세로 둘 다 (**요일 머리에도** 세로선)
수업 칩:        m-px border-2 · 학과색 테두리 + 8% 채움 · px-2 py-1.5
칩 · 지금:      #ff4eba 테두리 + 22% 채움 + 과목명도 핑크
칩 · 과목명:     13px font-black leading-[1.2] line-clamp-2 · **학과색**
칩 · 분반·교사:  12px font-bold black/45 — 같은 과목을 여러 선생님이 나눠 맡습니다
칩 · 교실:      12px font-bold black/45 — **이름 쪽에** 붙입니다
점심·저녁 띠:    **교시 칸에 비례**한 높이 · 빗금 rgba(0,0,0,0.06)
               ↳ 70분 점심이 16px 이면 50분 수업(64px)보다 짧아 보입니다
               ↳ 자보다 **옅습니다**(0.06 vs 0.13) — 면적이 커진 만큼 조용해야 합니다
               ↳ 이름은 왼쪽 교시 열에 12px black/45
스크롤:         max-h-[calc(100vh-14rem)] overflow-auto — 격자만 제 안에서 흐릅니다
PNG 내보내기:    `html-to-image` 의 `toPng` · **스크롤 상자가 아니라 안쪽 격자**를
               `scrollWidth/scrollHeight` 로 찍어야 잘린 교시까지 담깁니다
PNG · 강조 없이: 체크하면 **오늘 열·요일 머리·지금 칩**의 핑크를 뺀 채로 찍습니다
               ↳ 세 자리가 같은 값(`markDay`)을 보므로 한 군데만 남는 일이 없습니다
               ↳ ⚠️ 상태를 켠 **즉시 찍으면 강조가 그대로 담깁니다** — `requestAnimation
                 Frame` 을 두 번 넘겨 다시 그려진 뒤에 찍습니다
체크박스:        네모(`h-3.5 w-3.5 border-2`) + 켜지면 검은 면에 흰 체크
               ↳ 브라우저 기본 체크박스를 쓰면 이 화면에서 **유일하게 둥근 물건**이 됩니다
```

⚠️ **옅은 *회색*으로 칸을 그리지 마세요.** `bg-black/[0.05]` 로 뒀더니 한 주가 통째로
회색 얼룩이 되어 **어디가 비었는지 세어야** 알 수 있었습니다. 5% 회색은 아무 말도 안
합니다. (학과색 8% 는 다릅니다 — **무슨 과목인지**를 말하므로 정보입니다.)

⚠️ **칩 안의 글자를 가운데 정렬하지 마세요.** 연강 덩어리에서 이름이 두 교시 번호
**사이**에 걸려 6교시인지 7교시인지 알 수 없게 됩니다. 이름도 교시 번호도 **위쪽**입니다.

**오늘은 핑크로 칠합니다** — 머리 한 칸(25%)과 그 아래 열 기둥(7%)이 같은 색이라
한 덩어리로 읽힙니다. 한때 "핑크는 지금 하나뿐" 이라며 검정으로 뒤집어 뒀는데, 흰
바탕에 검은 칸 하나가 격자에서 제일 무거워 보였습니다.

⚠️ **핑크는 이제 세 농도로 씁니다** — 오늘 머리(25%)·오늘 열(7%)·지금 칩(22%). 셋 다
같은 것을 가리키므로(오늘 · 오늘의 지금) 뜻이 갈리지 않습니다. **네 번째 자리에 쓰면
그때는 정말로 갈라집니다.**

⚠️ **현재 교시 가로 띠는 뺐습니다.** 세로 기둥과 교차시켜 봤는데, 강조가 둘이 되니
격자가 십자로 갈려 보였습니다 — 오늘(세로) 하나만 남깁니다.

### 시간표에서 검색으로

**과목명·분반·교사 글자는 링크입니다** (주간 격자의 칩, 오늘 목록의 줄). 시간표를 보다가
궁금해지는 건 대개 "이 수업 누가 또 듣지", "이 선생님 다른 수업은" 이고, 그건 검색
화면의 일입니다.

```
과목명 → 그 과목        분반  → 그 분반만        교사 → 그 선생님 수업만
표시:  hover:underline (평소엔 밑줄 없음 — 칩 안에 밑줄이 셋이면 글자가 안 읽힙니다)
```

⚠️ **검색어를 손으로 만들지 마세요.** `searchEngine` 의 `subjectQuery`·`sectionQuery`·
`teacherQuery` 를 씁니다 — 괄호·`:`·`/` 가 전부 질의 문법의 글자라, 이름을 그대로 넘기면
`미적분학2(EC)` 의 `(EC)` 가 **논리식 괄호**로 파싱됩니다.

⚠️ **교실은 링크가 아닙니다.** 빈 교실 찾기(`/emptyroomfinder`)와 헷갈릴 자리라, 필요해
지면 그때 어디로 보낼지부터 정하세요.

놓은 것이라, 빼면 앱 곳곳의 드롭다운·인풋만 둥글어집니다.

## 넘치는 한 줄

문장 전체가 곧 내용인 자리(배너 등)는 `…` 로 자르지 말고 `MarqueeText` 를 씁니다 —
자르면 뒷말을 영영 못 읽습니다.

```
넘칠 때만 움직임 (ResizeObserver 로 다시 잼)
속도 45px/s 고정 · 양 끝에서 10%씩 멈춤 · 최소 6초
prefers-reduced-motion 이면 정지
```

목록의 과목명·교실처럼 **옆에 같은 정보가 또 있는 자리**는 그냥 `truncate` 로 둡니다.
움직이는 것이 늘어나면 정작 "지금" 이 안 보입니다.

## 나타났다 사라지는 버튼

같은 자리에서 모양이 바뀌는 버튼(확인 단계 등)은 **상자를 먼저 고정**합니다.

```
줄 높이 고정 (h-7 등)     ← 안 하면 아래 항목이 통째로 밀립니다
transition-colors        ← transition-all 은 폭까지 애니메이션합니다
whitespace-nowrap        ← 좁아지는 순간 글자가 접혀 아래로 삐져나옵니다
```

⚠️ `transition-all` + 고정 높이 + 긴 글자는 **글자가 상자 밖으로 나오는** 조합입니다.
폭이 애니메이션되는 100ms 동안 글자가 두 줄이 되는데 높이는 안 늘어나서요.

## 로딩 표시

`RetroSpinner` 를 씁니다. **HeroUI `<Spinner />` 는 이 프로젝트에서 동작하지 않습니다** —
`animate-spinner-ease-spin`·`w-5` 같은 클래스가 `node_modules` 안에만 있어서 Tailwind v4
가 유틸리티를 생성하지 않고, 회전 없는 **4px 세로선**으로 그려집니다. 원형 스피너는
전역 `rounded-none!` 오버라이드와도 싸웁니다.

생김새는 **paper-ui 의 `Spinner`** 를 옮겼습니다 — 옅은 링에 위쪽 한 조각만 진해서
회전이 읽힙니다.

```
rounded-full · border-black/15 · border-t-black · 900ms linear
sm 16px(2px) · md 20px(2px) · lg 28px(3px)
```
