# 시험 시간표

학교 공지의 시험 일정과 응시 명단을 저장해 본인 시험 시간표를 조회하는 기능입니다.

`ExamPeriod`는 학기·시험 종류·시험 기간·배너 노출 기간·원본 파일명과 SHA-256을
저장합니다. `Exam`은 시험 과목, 날짜, 실제 시작·종료 분, 공지의 시험실 배정 규칙을
저장합니다. `ExamRegistration`은 공지에 표시된 학생별 응시 대상과 해석된 시험실을
저장합니다. 별도 실시 시험은 날짜·시각을 비우고 안내문을 넣습니다.

응시 대상은 학교 공지 시점의 스냅샷입니다. 현재 수강 정보는 시험실을 분반에 연결할
때만 사용합니다. 공지와 현재 수강 데이터가 다를 때 응시 여부가 바뀌지 않습니다.
시험실이 여러 곳이고 수강 분반을 확인할 수 없으면 시험실을 임의로 선택하지 않고
원문 배정 안내를 반환합니다. 공지 명단은 Git에 넣지 않습니다.

## 적재

`backend/cli/import_exams.py`는 이미 정규화한 JSON 두 파일을 읽습니다. 엑셀 양식은 매번
다르므로 앱에는 범용 파서나 Admin 업로드를 넣지 않습니다. 공개 일정은
`backend/exam_seed.json`, 비공개 명단은 서버 `data/exams/`에 보관합니다.

적재 전 확인 명령입니다.

```bash
python3.14 -m backend.cli.import_exams --registrations data/exams/2026-2-midterm-registrations.json --dry-run
```

확인 후 `--dry-run`을 빼면 SQLite backup API로 복사본을 남기고 해당 회차만
트랜잭션 안에서 교체합니다. 다른 시험 회차와 수강·학사일정은 수정하지 않습니다.
시험 키, 날짜·시각, 학생 존재 여부, 중복 명단을 검증한 뒤 저장합니다.

2026-2 원본은 `중간시간표(2026-2)`의 반복 표기를 시험별로 합친 60건과 별도 실시
1건입니다. 응시자는 `중간기말 실시과목(전체-정리완)`의 수강 표시를 중심으로
국내·국제반을 구분했습니다. `수강 현황`의 빈 칸을 미수강으로 해석하면 국내반
시험이 다수 빠집니다. 이 추출 과정은 2026-10-05의 Bufs에 보관했습니다.

### 2026-2 기말고사 (`exam_seed_2026-2-final.json`)

중간고사 seed(`exam_seed.json`)를 덮지 않고 회차마다 파일을 둡니다. 적재는 `--seed` 로
고릅니다.

```bash
python3.14 -m backend.cli.import_exams --seed data/exams/exam_seed_2026-2-final.json \
  --registrations data/exams/2026-2-final-registrations.json --dry-run
```

원본(ksain 3092번 글의 xlsx)은 시트 구성이 중간고사와 다릅니다 — `기말시간표(2026-2)`
(66건, 별도 실시 `이산구조` 포함)와 `수강 현황` 만 있고 **`실시과목` 시트가 없습니다.**

⚠️ **`수강 현황` 에 1학년 필수 과목 15개의 응시 표시가 없습니다.** 26학번 126명이 행은
있는데 표시가 통틀어 4개뿐이라 `미적분학1`·`수학2`·`영어Ⅱ`·`물리학및실험1`·`화학및실험`·
`생물학및실험`·`정보과학2(국내반)`·`한국사` 등이 빈 시험이 됐습니다. 그 15개만 **적재 시점의
2026-2 수강 정보로 채웠습니다** — 위의 "공지 시점 스냅샷" 원칙의 예외입니다. 국내반·국제반은
중간고사 응시 기록이 연결된 분반으로 갈랐습니다(`수학1`: 1분반 = 국제반, 2분반 = 국내반,
`정보과학2(국내반)` = 전체 수강생 − 시트의 국제반 응시자). 표시가 있는 51개 시험은 시트를
그대로 썼고 DB 수강생과 1~5명 차이였습니다.

결과는 66개 시험, 응시 1,779건(365명), 분반 미연결 40건, 시험실 미확정 5건입니다. 배너는
처음에 중간고사와 같은 간격(시험 1주 전, 11/30)으로 잡았다가, 운영자 요청으로 **시간표가 나온 뒤인 10/29 부터**
띄웁니다 — 중간고사 배너도 시간표가 나온 날부터 떴습니다. 바꾼 건 seed 의 `visible_from` 과 운영 DB 의 그 칸
하나라서, 다시 적재하지 않았습니다. 10교시 `미적분학3(EC)`·`수학적모델링`
은 원문대로 19:30–23:30 입니다. 추출 스크립트는 2026-10-28 의 Bufs(`final-exam/`)에 있습니다.

## 조회와 배너

`routers/exams.py`의 `GET /exams/me?year=&semester=`는 인증한 계정의
`effective_stu_id`만 조회합니다. 학번을 외부 파라미터로 받지 않습니다.
선택 학기의 최신 시험 회차와 날짜별 개인 시험·별도 실시 안내를 반환합니다.
조회는 `services/exams.py`의 `exams_for()`가 하고, Ask의 `my_exams` 도구도 같은 함수를
씁니다 — 본인 것만 나간다는 경계를 한 곳에 두려는 것입니다.

`services/exams.py`의 `active_period()`는 서버 KST 날짜와 선택 학기로 노출 여부를
판정합니다. `/home`의 `exam_period`가 활성 회차의 요약을 보내며, 배너가 `/exams`로
연결됩니다. 2026-2 중간고사의 배너는 10월 5~16일, 시험은 10월 12~16일입니다.
배너 기간이 끝나도 저장한 시험 시간표는 주소로 조회합니다.
