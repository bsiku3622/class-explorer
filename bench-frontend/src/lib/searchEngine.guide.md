# lib/searchEngine.ts Guide (ksa-bench)

> [← Frontend Guide](../../CLAUDE.md)

## 무엇을 검색하나

**과목·교사·강의실만** 봅니다. 학생은 여기 없습니다 — 명단이 클라이언트에 내려오지
않으므로 훑을 대상 자체가 없고, 사람은 `lib/benchApi.ts` 로 서버에 한 명씩 물어봅니다.

class-explorer 쪽 엔진(`frontend/src/lib/searchEngine.ts`, 647줄)과는 다른 파일입니다.
거기서 없앤 것과 이유:

| 없앤 것 | 이유 |
| --- | --- |
| 불린 연산 (`+ & / ( ) !`) | `25-001+25-002+…` 로 한 방에 전교생이 긁힙니다. 문법을 없애면 UI 규칙이 아니라 **구조**가 됩니다 |
| 초성 매칭 | `ㄱㅊㅅ` 하나로 수십 명이 걸리는 열거 지렛대였습니다 |
| 학생 축 | 명단이 없습니다 |
| 유사도(fuzzy) 매칭 | 부분 일치로 충분하고, 느슨할수록 한 질의에 많이 걸립니다 |

## 남은 문법

```
영어              과목명·교사·강의실 부분 일치
t:김효진          교사 (te·teacher 도 됨)
r:301             강의실 (ro·room 도 됨)
체육4/2,3         과목 뒤에 분반 번호. 여러 개는 콤마
```

로마숫자는 아라비아로 바꿔서 비교합니다 (`영어Ⅲ` → `영어3`). 공백·대소문자는 무시합니다.

## 내보내는 것

| | |
| --- | --- |
| `parseQuery(term)` | `{ mode, query, sections }` — 접두사와 분반 번호를 떼어 냅니다 |
| `searchInClient(allData, term)` | `{ data, entities, mode, stats }` |

`entities` 는 `mode` 가 `teacher`·`room` 일 때만 채웁니다 (`buildEntities`). 일반 검색은
과목 목록만 돌려주므로 빈 배열입니다.

`stats` 에 `total_matched_students` 는 없습니다 — 셀 명단이 없습니다.
학년 필터 인자(`selectedYears`)도 없습니다. 분반을 학년으로 거르려면 그 분반에 누가
있는지 알아야 하는데, 그게 바로 없앤 것입니다.
